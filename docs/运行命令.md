# 运行命令

以下命令都在仓库根目录执行。先安装依赖：

```bash
python -m pip install -r requirements.txt
```

## 1. 生成无噪声数据

```bash
python simulation.py \
  --output outputs/clean_seed20261015.npz \
  --instances 1000 \
  --samples-per-circle 100 \
  --seed 20261015 \
  --noise-std 0
```

## 2. 生成有噪声数据

下面的例子只给每帧平移向量加标准差为 1 mm 的高斯噪声，不加入结构化离群点：

```bash
python simulation.py \
  --output outputs/noise_1mm_seed20261015.npz \
  --instances 1000 \
  --samples-per-circle 100 \
  --seed 20261015 \
  --noise-std 0.001 \
  --noise-seed 20261016
```

三个随机种子的职责不同：

- `--seed`：固定每个仿真实例的 `tx、ty、tz、rmin、rmaj` 和传感器安装旋转；
- `--noise-seed`：固定加到每帧平移向量上的高斯噪声；
- `--sac-seed`：固定 RANSAC/MemorySAC 在运行时随机抽取的三点组合。

## 3. 选择 None、RANSAC 或 MemorySAC

`--sac` 不区分大小写，下面三个值均可直接输入。

### 3.1 不筛选内点：None

```bash
python PerpAdapt.py \
  --dataset outputs/clean_seed20261015.npz \
  --method PPC \
  --sac None
```

无离群点的无噪声或高斯噪声实验建议先用 `None`，此时直接用一条轨迹上的全部点
做 SVD 平面拟合和二维圆拟合。

### 3.2 使用 RANSAC

```bash
python PerpAdapt.py \
  --dataset outputs/clean_seed20261015.npz \
  --method PPC \
  --sac RANSAC \
  --num-iterations 100 \
  --distance-threshold 0.005 \
  --min-triangle-quality 0.01 \
  --max-sampling-attempts 10000 \
  --sac-seed 20261017
```

### 3.3 使用 MemorySAC

```bash
python PerpAdapt.py \
  --dataset outputs/clean_seed20261015.npz \
  --method PPC \
  --sac MemorySAC \
  --checkpoint net.pth \
  --num-iterations 100 \
  --distance-threshold 0.005 \
  --min-triangle-quality 0.01 \
  --max-sampling-attempts 10000 \
  --sac-seed 20261017 \
  --update-rate 0.001
```

MemorySAC 需要 `torch`、`torchdiffeq` 和与当前网络结构匹配的 `net.pth`。
`--checkpoint` 只在 `--sac MemorySAC` 时读取；运行 `None` 或 `RANSAC` 时不会导入
MemorySAC，也不会加载模型。

## 4. 选择 PPC、Lee(4) 或 Lee(6)

`--method` 可选：

| 参数 | 实际方法 | 使用轨迹数 |
| --- | --- | ---: |
| `PPC` | 修正 PPC | 2 |
| `Lee4` | 修正 Lee PC(4) | 4 |
| `Lee6` | 修正 Lee PC(6) | 6 |

例如：

```bash
python PerpAdapt.py --dataset outputs/clean_seed20261015.npz --method Lee4 --sac RANSAC
python PerpAdapt.py --dataset outputs/clean_seed20261015.npz --method Lee6 --sac None
```

三种标定方法都可以与三种 `--sac` 选项组合。

## 5. 三点近似共线判定

RANSAC 和 MemorySAC 每次用三点建立最小圆模型。代码计算无量纲质量：

```text
q = ||(p1-p0) x (p2-p0)|| / max(||pi-pj||^2)
```

若 `q < --min-triangle-quality`，说明三点共线或近似共线，代码不会用它计算圆心，
而是重新抽取三点。默认阈值为 `0.01`。由于分子和分母同时随长度单位平方缩放，
该判定不受世界坐标系平移、旋转或米/毫米单位变化影响。

`--num-iterations` 指需要得到的有效圆假设数；退化抽样不计入有效假设。
`--max-sampling-attempts` 是为获得这些有效假设所允许的总抽样次数，超过后程序会明确
报错，而不是继续使用数值不稳定的圆。

## 6. 其他常用参数

```bash
# 只运行前 10 个实例
python PerpAdapt.py --dataset outputs/clean_seed20261015.npz --limit 10

# 从第 100 个实例开始运行 20 个实例（下标从 0 开始）
python PerpAdapt.py --dataset outputs/clean_seed20261015.npz --start 100 --limit 20

# 旧数据没有 samples_per_circle 元数据时显式指定每条轨迹 100 帧
python PerpAdapt.py --dataset dataset.npz --samples-per-circle 100 --method PPC --sac None

# 查看全部参数
python PerpAdapt.py --help
```

`--distance-threshold` 与数据中的位置使用同一个长度单位。当前仿真数据的单位为米，
所以 `0.005` 表示 5 mm。

## 7. 一次性比较三个修正方法

`evaluate_corrected.py` 的 `--sac` 会同时作用于 PPC、Lee(4)、Lee(6)。三个方法
分别获得一个参数相同、随机种子相同的新 SAC 实例，避免前一个方法消耗的随机状态
影响后一个方法。

全部不筛选内点：

```bash
python evaluate_corrected.py \
  --dataset outputs/clean_seed20261015.npz \
  --sac None \
  --json outputs/clean_metrics.json
```

全部使用 RANSAC：

```bash
python evaluate_corrected.py \
  --dataset outputs/clean_seed20261015.npz \
  --sac RANSAC \
  --num-iterations 100 \
  --distance-threshold 0.005 \
  --min-triangle-quality 0.01 \
  --max-sampling-attempts 10000 \
  --sac-seed 20261017 \
  --json outputs/ransac_metrics.json
```

全部使用 MemorySAC：

```bash
python evaluate_corrected.py \
  --dataset outputs/clean_seed20261015.npz \
  --sac MemorySAC \
  --checkpoint net.pth \
  --num-iterations 100 \
  --distance-threshold 0.005 \
  --min-triangle-quality 0.01 \
  --max-sampling-attempts 10000 \
  --sac-seed 20261017 \
  --update-rate 0.001 \
  --json outputs/memorysac_metrics.json
```

这些参数与 `PerpAdapt.py` 的 SAC 参数含义完全一致。输出表头会显示当前 `sac`，
JSON 中每个方法的结果也会记录 `sac` 和 `sac_seed`。
