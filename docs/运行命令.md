## 1. 生成无噪声数据
```bash
python simulation.py \
  --output outputs/clean_seed20261015.npz \
  --instances 1000 \
  --samples-per-circle 100 \
  --seed 20261015 \
  --noise-std 0
```

## 2. 生成有噪声数据
```bash
python simulation.py \
  --output outputs/noise_1mm_seed20261015.npz \
  --instances 1000 \
  --samples-per-circle 100 \
  --seed 20261015 \
  --noise-std 0.001 \
  --noise-seed 20261016
```

这里的随机种子固定的是仿真数据生成过程

seed：
固定每个仿真实例的 tx、ty、tz、rmin、rmaj，以及传感器随机安装旋转 R_1

noise-seed:
固定加到每一帧平移向量 p_i 上的高斯噪声

## 3. 对比方法
```bash
python evaluate_corrected.py \
```
